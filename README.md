# 你好，我是 missile

坐标广东，还在念书。GitHub 上的东西基本都长在同一个方向上：给身边人做点真能用的学习工具。以前 ID 叫 Yihggh，改过来之后老仓库的链接懒得一一换，就一直留到现在。

写完回头看，四个拿得出手的项目全是教育向，可能我天生就爱管别人学习。

**[你缺失的那门手机课](https://github.com/ClassTechStar/Your-Missing-Phone-Class)**——起因是我爸妈老问我「存储满了删什么」「这条中奖短信是真的吗」，市面上的书要么太浅要么像维修手册，索性自己写一本。后来就没收住：84 章、19 种语言、Web/PWA/APK/PDF 四种形态，连文言文版都有。给阿拉伯语和希伯来语调从右往左排版的那几天，我一直在怀疑自己图什么。

**[高中物化生语数英学习大礼包](https://github.com/ClassTechStar/High-School-Physics-Chemistry-and-Biology-Study-Bundle)**——给广东高考做的纯前端工具，没有后端没有账号，学习记录全存本地。同类平台靠服务器收数据活着，我就想证明不收数据也能做成同样的事。情境题全是广东的东西：广州塔的电梯、潮汕工夫茶的水垢、茂名荔枝园的鸡。为了让正确答案别老扎堆在 A，把两百道题的选项整个换了个位置；题库里 520 道重复题，也是一条条比对下来删掉的。

**[SmartSideBAR](https://github.com/ClassTechStar/SmartSideBAR)**——给希沃一体机做的侧边工具栏。现有的教学软件普遍两件事没做好：批注只能画不能认，工具不懂课表。所以它能把手画的圆自动掰成正圆、手写板书离线转成文字、到点自动切上课模式，放学还会弹一句「已放学，辛苦了」。最早用 Electron 写，后来嫌 100MB 太离谱，用 C# 整个重写一遍，压到 32MB。

**[知债：星穹学途](https://github.com/ClassTechStar/Knowledge-Debt-Astral-Path)**——从毕业论文里长出来的项目，名字明牌致敬崩坏：星穹铁道。想解决的事很简单：跨课程卡住你的，往往不是眼前这一章，而是前面某门课欠下的先修债。它帮你把债找出来、排出做得完的计划、一点点销掉。底线写死在代码里：数字只能算出来，AI 不许改分。

一些习惯：

- 注释写「为什么」，不写「做了什么」
- 架构文档是写给后来接手的人看的——包括过几个月忘了细节的自己
- README 里每个数字都得有脚本核对，漂移了 CI 会直接红
- 讨厌宣传腔，之前专门有个提交叫「重写 README，去掉宣传腔」
- 液态玻璃染上瘾了，四个项目没一个逃掉

AI 写代码我用得很凶，但规矩是它打草稿、我签字，合并前每一行都得自己认过。

现在混在 [SECTL](https://sectl.cn)（做班级开源工具的社区）里，GitHub 组织栏填的也是它。ClassIsland 的代码常去偷师，朋友的背诵工具（ReciteHelper、Reciting-us）也帮忙打过下手。最近在给几个项目准备比赛，答辩脚本写了三份，比写代码还累。

B 站同名 [@ClassTechStar](https://space.bilibili.com/702063384)，偶尔发点项目演示。过去一年提交了一千七百多次，不少落在凌晨两点以后，别学我。

永远相信美好的事情即将发生。
